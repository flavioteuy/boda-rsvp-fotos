    Almacenamiento de fotos y videos

    Solo se ofrecen como disco externo las carpetas de /media que realmente son un disco distinto al interno. Si el disco se desconecta, las subidas siguen funcionando y se guardan temporalmente en el almacenamiento interno.

    Probar subidas desde internet (error 413)

    Si al subir música, fotos o videos por internet aparece «413 Request Entity Too Large» o «el archivo es demasiado grande», pero desde tu red local (por la IP) funciona, el límite lo pone el servidor web que está delante del add-on (Nginx Proxy Manager, el proxy de Nginx de Home Assistant, etc.) y no el add-on. Los invitados también se ven afectados: sus fotos y videos pasan por el mismo lugar.

    Cómo subir el límite en el proxy

    Nginx Proxy Manager: Hosts → Proxy Hosts → los tres puntitos de tu dominio → Edit → pestaña Advanced → en «Custom Nginx Configuration» escribí client_max_body_size 600M; → Save.

    Otro Nginx (por ejemplo el add-on «NGINX Home Assistant SSL proxy» con configuración personalizada): agregá client_max_body_size 600M; dentro del bloque server { … } de tu dominio y reiniciá el proxy.

    Caddy: request_body { max_size 600MB } dentro del sitio. Apache: LimitRequestBody 0.

    Cloudflare (si tu dominio pasa por su proxy naranja): el plan gratuito limita cada pedido a 100 MB y no se puede subir.

    600M alcanza para lo máximo que acepta el sitio (500 MB por archivo). Después de cambiarlo, volvé a tocar el botón de arriba para confirmar.
